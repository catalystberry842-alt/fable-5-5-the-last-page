# The Last Page — Fable 5.5

A 60-second, 24 fps 2D anime launch film for **Fable 5.5**, delivered as a single self-contained HTML file (`index.html`) with original artwork, animation, orchestral/felt-piano score, and sound design.

- **Watch**: Open `index.html` directly in any browser (or via GitHub Pages).
- **Format**: 1280×720, 24 fps H.264 + 48 kHz stereo AAC, pre-rendered and embedded in a black letterboxed cinema frame with a single quiet play button.
